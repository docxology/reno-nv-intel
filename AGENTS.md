# Reno regional consumer

All implementation belongs in `docxology/region-intel`. This repository owns JSON configuration, retained public evidence, scholarly sources, native review packets, a small shared-runner importer, consumer acceptance and workflows. Never copy shared methods here. Use Bun 1.4.2 and the frozen lockfile. Read docs/sources.md before changing policy. Run validate, documents:check, pages:export, pages:validate and publication:check. Manuscripts must use the real pinned docxology/template API. Never relabel PDF pages or extracted lines as legal articles or sections. Preserve source rights, jurisdiction, source clocks, unavailable/stale states and failed evidence. Follow enclosing GitVault admission and storage guidance. Independent review must be performed by someone who did not build the work.
