# Composition and ownership

Reno JSON identity + policy + source catalog → immutable region-intel dependency → bounded acquisition and replay → retained evidence → shared Pages and native manuscript projection → pinned docxology/template → separately reviewed artifacts.

Only scripts/region.ts imports the shared CLI. The consumer has no runtime source directory, scraper, parser or renderer. Shared public-PDF support is independent of eCode360. It uses source-matched descriptors, original PDF hashes, every physical page and exact extraction replay. Static search returns physical pages, not inferred legal sections. Full native outputs and offline assets are composed into Pages by the shared exporter.

The public seed is an observation, not a clock-resettable cache. A static rebuild preserves its acquisition time. A dependency upgrade, policy change or refreshed source requires revalidation and a new manuscript fingerprint. The upstream core and template pins are public immutable commits. No sibling checkout or file dependency is needed to run acceptance.
